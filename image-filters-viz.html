What Filter Values Mean

Filter weights define a weighted sum over a local pixel neighborhood. The spatial arrangement of + and − values encodes exactly which mathematical operation is performed — and which image structures produce a response.

Principle 1
Weights that sum to 1

Smoothing filters. A uniform region stays the same value. These filters measure signal level — they blur by averaging neighboring pixels.

output(flat region) = value × Σwᵢ = value × 1 = value
Σ weights = 1 · Smoothing
Principle 2
Weights that sum to 0

Derivative filters. Produce zero on uniform regions. Only fire where there is change. Used for edge and corner detection.

output(flat region) = value × Σwᵢ = value × 0 = 0
Σ weights = 0 · Derivative

Smoothing Filters

Both filters compute a weighted average. The difference is how they weight neighbors. Weights sum to 1 — a flat region passes through unchanged.

Box Filter
Every neighbor counts equally
f_out = (1/9) Σ f(xᵢ)

Simple arithmetic mean over the 3×3 patch. A pixel 2 steps away is weighted identically to one directly adjacent. This causes visible "blocky" blurring because it doesn't respect distance.

Gaussian Filter
Closer pixels weighted more
G(x,y) = (1/2πσ²) · exp(−(x²+y²)/2σ²)

Sample the 2D Gaussian at integer offsets, then normalize. The center gets weight 4, edges get 2, corners get 1 — naturally falling off with distance.

The 2D filter is the outer product of [1,2,1] with itself. Center = 2×2 = 4. Corner = 1×1 = 1. This separability means you can apply two 1D passes instead of one 2D pass — faster computation.

Derivative Filters

Derived from finite difference approximations of derivatives. Weights sum to zero — zero response on flat regions, large response where intensity changes.

From 1D Calculus
Finite Difference → Filter Weights

The derivative approximation directly gives the kernel weights:

f'(x) ≈ f(x+1) − f(x−1) → [−1, 0, +1]
f''(x) ≈ f(x+1) − 2f(x) + f(x−1) → [1, −2, 1]

Apply twice: [−1,1] convolved with [−1,1] = [1,−2,1]. This is how the Laplacian center weight of −4 arises: −2 from x-direction + −2 from y-direction.

Prewitt vs Sobel
Smoothing strategy differs

Both compute a 1st derivative. The difference is how they smooth perpendicular to the gradient direction:

Prewitt — equal rows [1,1,1]
Sobel — Gaussian rows [1,2,1]

Sobel weights the center row (closest to the point of interest) twice as much. The ±2 come entirely from the smoothing weights — not from the derivative itself.

2nd Derivative
Laplacian: ∇²f = ∂²f/∂x² + ∂²f/∂y²
Center −4 =
−2 (from x) +
−2 (from y)

Detects rapid changes in gradient. Zero-crossings mark edge locations precisely. Flat region → 0. Peak → large negative. Edge → sign flip on either side.

Smoothed 2nd Derivative
Laplacian of Gaussian (LoG)
LoG(x,y) = −(1/πσ⁴)[1 − (x²+y²)/2σ²] · exp(−(x²+y²)/2σ²)

"Mexican hat" shape: positive center, negative surround. Smooth first to avoid amplifying noise (differentiation amplifies high frequencies). Fires at blobs whose size matches σ.

Corner Detection — Harris

A corner is where intensity changes in both directions simultaneously. No single gradient filter captures this. Harris combines both gradient directions through the structure tensor.

Structure Tensor
M = Σ [ Iₓ² · IₓIᵧ ; IₓIᵧ · Iᵧ² ]

Compute at every pixel:

Iₓ = response of horizontal gradient filter
Iᵧ = response of vertical gradient filter

Build the 2×2 structure tensor M, then examine its eigenvalues λ₁, λ₂ to classify the local structure.
