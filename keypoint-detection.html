What Makes a Good Keypoint?

Keypoints (interest points) are distinctive locations in an image used for matching, tracking, and reconstruction. Not every pixel qualifies — good keypoints must satisfy several geometric properties.

🎯
Repeatability
The same keypoint can be reliably detected across different views, illuminations, and scales of the same scene. Essential for multi-image matching.
🔍
Distinctiveness
The local patch around the keypoint has rich, unique intensity patterns that can be discriminated from other patches. Avoids ambiguous matches.
📍
Localization
The position can be determined precisely, ideally to sub-pixel accuracy. Poor localization propagates geometric errors downstream.
🔢
Quantity
Sufficient keypoints exist across the image to enable dense correspondence. Sparse keypoints leave regions unrepresented.
⚡
Efficiency
Detection must be computationally tractable for real-time applications like SLAM, AR, and video tracking.
🔄
Invariance
Robust under photometric (brightness, contrast) and geometric (rotation, scale, viewpoint) transformations to a useful degree.
Why Corners? — The Aperture Problem

When you observe a small image patch through a window (aperture), flat regions look the same in all directions. Edges constrain motion in one direction only. Corners are uniquely localizable — they constrain motion in ALL directions. This makes them ideal keypoints.

■ Flat Region
No gradient in any direction
Cannot localize
■ Edge
Gradient along one direction
Partially localizable
■ Corner
Gradient in all directions
Fully localizable ✓
The Structure Tensor

The key insight: shift a small window W around a point (x,y) and measure how much the intensity changes. The autocorrelation function E(u,v) captures this. Taylor expansion leads to the Structure Tensor (Second Moment Matrix) M.

Deriving the Autocorrelation Function
E(u,v) = ΣW w(x,y) [I(x+u, y+v) − I(x,y)]²
// Sum of squared differences when window shifts by (u,v)

For small shifts, Taylor expand: I(x+u, y+v) ≈ I(x,y) + Ixu + Iyv

E(u,v) ≈ ΣW w(x,y) [Ixu + Iyv]²

= [u v] · M · [u v]ᵀ

// Quadratic form in (u,v)

The Harris Corner Response

Computing eigenvalues explicitly is expensive. Harris & Stephens (1988) derived an elegant approximation using only the determinant and trace of M — quantities that are cheap to compute.

From Eigenvalues to Response Function
// Exact (expensive): check λ₁ and λ₂ directly
det(M) = λ₁·λ₂    trace(M) = λ₁ + λ₂

// Harris response (cheap):
R = det(M) − k · trace²(M)

R = λ₁λ₂ − k(λ₁ + λ₂)²

// k = empirical constant ∈ [0.04, 0.06]

The k parameter controls sensitivity. Large k → fewer corners detected (stricter). Small k → more corners (looser). Typical k = 0.05.

Harris Response Space

The 3 regions of the λ₁-λ₂ plane correspond to flat, edge, and corner classifications.

R > threshold → CORNER
R < −threshold → EDGE
|R| small → FLAT
The hyperbolic boundary curves arise from:

R = λ₁λ₂ − k(λ₁+λ₂)² = 0

Along this curve: λ₂/λ₁ satisfies a quadratic in terms of k. The corner region (R > 0 and large) occupies the upper-right quadrant where both eigenvalues are large and balanced.
k parameter
0.050
Alternative: Shi-Tomasi Criterion
R = min(λ₁, λ₂)
// Keep pixel if both eigenvalues are large
// Simpler but requires explicit eigenvalue computation
// Better for tracking (used in OpenCV goodFeaturesToTrack)

Shi-Tomasi detects corners where the minimum eigenvalue exceeds a threshold — guaranteeing both directions have sufficient gradient strength. Empirically produces better features for KLT tracking than Harris.

Harris Detector Algorithm

The complete pipeline from image to detected corners, step by step.

  • 1
    Compute Image Gradients
    Apply Sobel or Gaussian derivative filters to get Ix and Iy at each pixel.
    Ix = ∂I/∂x ≈ I * [-1 0 1]    Iy = ∂I/∂y ≈ I * [-1 0 1]ᵀ
    Then compute products: I²x, I²y, IxIy
  • 2
    Gaussian Smoothing of Gradient Products
    Apply a Gaussian window w(x,y) to the gradient products. This accumulates gradient information over a neighborhood and reduces noise sensitivity.
    Axx = G * I²x    Ayy = G * I²y    Axy = G * IxIy
  • 3
    Compute Response Function R
    For each pixel, assemble M from the smoothed gradients and compute:
    det(M) = Axx·Ayy − A²xy
    trace(M) = Axx + Ayy
    R = det(M) − k · trace²(M)
  • 4
    Threshold the Response
    Keep only pixels where R > τ (threshold). This eliminates flat regions and edges, retaining candidate corners. τ is typically set as a fraction of max(R).
  • 5
    Non-Maximum Suppression (NMS)
    Within a local neighborhood (e.g., 3×3 or 5×5 window), keep only the pixel with the highest R value. This prevents multiple detections for the same corner and ensures well-separated keypoints. Result: a sparse set of corner locations.

Invariance Properties

Understanding when Harris corners remain stable across image transformations — and when they don't — is crucial for knowing when to use them vs. more sophisticated detectors.

Translation Invariant
Harris is fully invariant to translation. Moving the image doesn't change gradient magnitudes or their spatial relationships. Detected corners shift by the same translation vector.
Rotation Invariant
The eigenvalues λ₁, λ₂ of M are rotationally invariant (they're scalar invariants of the matrix). The corner response R = det(M) − k·trace²(M) is therefore invariant to image rotation. The same corners are detected regardless of orientation.
Photometric Invariant (Additive)
Additive intensity shift I → I + c does not change gradients (∂(I+c)/∂x = ∂I/∂x). Harris is completely invariant to global brightness changes. Same corners detected under different ambient lighting.
Photometric — Multiplicative (Partial)
Multiplicative change I → αI scales gradients by α, M by α², det(M) by α⁴, trace² by α⁴. Thus R scales by α⁴. The ordering of responses is preserved, but absolute values change. Corner locations are invariant but threshold choice matters.
Not Scale Invariant ✗
Harris is NOT invariant to scale. A corner at scale σ₁ may appear as an edge or flat region at a different scale. The fixed Gaussian window size means features detected at one scale are missed at another. Scale-invariance requires multi-scale approaches (e.g., SIFT, LoG blobs, scale-space theory).
Not Affine Invariant ✗
Harris is sensitive to affine transformations (shear, non-uniform scaling). The elliptical shape of the structure tensor changes under affine warps. The Harris-Affine detector (Mikolajczyk 2004) extends Harris with affine normalization using the second moment matrix's shape to warp patches to a canonical form.
