What Is Image Segmentation?
partition pixels into coherent, meaningful regions
Overview ›

Goal: Identify groups of pixels that "go together" — partition an image into regions corresponding to meaningful objects or structures.

In biomedical imaging this is critical: you can't measure tumor volume, quantify gray matter, or track a carotid artery without first delineating the structure.

Types of segmentation results:

  • Oversegmentation — too many regions; correct objects are split
  • Undersegmentation — too few regions; distinct objects are merged
  • Multiple segmentations — a range of plausible results at different granularities

Limitations of manual segmentation:

  • Extremely slow — up to 60 hours per scan
  • High inter-rater variability — up to 15% disagreement between expert annotators [Warfield]

Thresholding & Histogram Methods
global · local (adaptive) · GMM · Otsu
Thresholding ›

The simplest approach: assign each pixel to foreground/background based on its intensity vs. threshold τ.

f(x,y) = { 1 if I(x,y) ≥ τ { 0 otherwise

When it works: segmenting a single object class (e.g., all bone in CT).

When it fails: multiple objects of similar intensity, uneven illumination.

Global vs. Local Thresholding

A single global threshold breaks down with non-uniform illumination (e.g., fluorescence microscopy). Local (adaptive) thresholding computes a different threshold per region:

  • Block thresholding — partition into rectangular blocks, one threshold per block
  • Moving window — slower but smoother; threshold at each pixel from local neighborhood

Automatic Threshold via Histogram

The histogram often shows two peaks (background / foreground) separated by a valley. Strategy: fit Gaussians (GMM) and use their intersection as threshold.

Key limitation: number of Gaussians to fit requires prior knowledge of tissue classes.

03
Connected Component Analysis (CCA)
label disconnected blobs · 2-pass algorithm · equivalence table
CCA ›

Thresholding gives a binary image but doesn't distinguish which foreground pixels belong to which object. CCA solves this.

Core idea: Two pixels belong to the same object if connected through a chain of foreground pixels (not separated by background).

Two-Pass Algorithm

  1. Pass 1 — scan top-to-bottom, left-to-right. At each foreground pixel, examine already-scanned neighbors:
    • All 0 → assign a new label
    • Exactly one neighbor is 1 → assign that neighbor's label
    • Multiple neighbors, different labels → assign one; record equivalence
  2. Pass 2 — merge equivalent labels so all pixels in the same region share one label.

The equivalence table tracks which provisional labels refer to the same component and collapses them.

Active Contours (Snakes)
energy minimization · internal + external · Kass 1987
Snakes ›

Motivation: Many real biomedical boundaries are partially invisible (e.g., carotid artery in ultrasound). Thresholding or edge detection alone will fail — you need to "hallucinate" missing boundaries guided by shape priors.

Seminal paper: Kass, Witkin & Terzopoulos · Snakes: Active Contour Models · ICCV 1987

Three-Step Process

  1. Initialize the contour near the target
  2. Evolve — iteratively move each vertex to reduce total energy ("wiggling snake")
  3. Stop — when contour aligns with boundary (energy minimum)

Contour Representation

Discrete parametric: a list of N 2D vertices v = {(x₁,y₁), ..., (xₙ,yₙ)}

Energy Function

E_total = E_external + E_internal E_external(vᵢ) = -|∇I(vᵢ)|² ← attracted to edges (high gradient) E_internal = α·Σ|vᵢ - vᵢ₋₁|² ← tension / elasticity + β·Σ|vᵢ₊₁ - 2vᵢ + vᵢ₋₁|² ← stiffness / curvature

Atlas-Based Segmentation
probabilistic atlas · Bayesian MAP · multi-tissue
Bayesian ›

When you have strong anatomical prior knowledge — e.g., all healthy brains have gray matter, white matter, and CSF in predictable spatial locations — bake that into segmentation as a probabilistic atlas.

Probabilistic Atlas

An atlas encodes the spatial distribution of anatomical structures across a population:

P(label = k | position x) where k ∈ {gray matter, white matter, CSF, ...} Constraint: Σₖ P(label = k | x) = 1 at every voxel

How to build an atlas:

  1. Gather population images of the same organ/anatomy
  2. Obtain manual expert annotations for each image
  3. Register all images to a common coordinate space
  4. Compute label distribution at each voxel across subjects

Bayesian MAP Segmentation

label*(x) = argmax_k P(I(x) | label=k) · P(label=k | x) ────────────── ──────────────── Likelihood Atlas Prior

This balances two extremes: pure atlas (ignores image data) vs. pure thresholding (ignores anatomy).
